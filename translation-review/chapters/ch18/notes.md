## 术语选择

| 英文 | 译法与边界 |
| --- | --- |
| build / build process | 构建／构建过程；执行构建是过程，所得文件是产物，不再用“创建构建”混指二者。 |
| artifact / artifact-based | 构建产物，明确语境后简称产物；基于产物的构建系统。不是组件、构建目标或“构建”这个动作。 |
| target | 构建目标／目标；由构建文件定义，规定可构建单元，对应产物，不与产物本身混同。 |
| task / command / action / rule | 任务／命令／动作／规则。保留第237行对 Ant 自身 target、task 命名与本章术语不同的说明。 |
| dependency | 表示对象时用依赖项，表示关系或声明时用依赖关系／依赖声明；不再“下载依赖关系”。 |
| transitive dependency | 传递依赖／传递依赖项，明确递归展开关系，纠正“横向依赖”。 |
| deterministic / reproducible | 确定性／可复现性；输出确定与跨机器复现是相关但不同的性质。 |
| worker / build master | 工作节点／构建主控节点，不译为管理员或笼统的主机。 |
| toolchain / host / target platform | 工具链／宿主平台／目标平台，区分在哪里构建和为哪个平台编译。 |
| artifact repository | 产物仓库，与源代码仓库、代码库区分。 |
| One-Version Rule / diamond dependency | 单版本规则／菱形依赖。 |
| semantic versioning / monorepo | 语义化版本管理／单体代码仓库；既有链接标签“语义版本字符串”完整保留。 |
| vendor / vendoring | 将依赖项纳入项目代码仓库；首次保留 vendoring，说明可纳入源代码或二进制文件。 |
