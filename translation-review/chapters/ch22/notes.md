## 术语与边界

| 英文 | 本章处理 |
| --- | --- |
| large-scale change / LSC | 大规模变更；逻辑相关但实际无法作为一个原子单元提交的一组变更，不等于单次大型提交。 |
| atomic / nonatomically | 原子／以非原子方式；整体不能原子提交，不代表拆出的分片也不能原子提交。 |
| shard / sharding | 分片；不是版本控制分支，也不是泛指分区。 |
| master / parent / global change | 总变更／全局变更；不是主分支。 |
| rollback / regression / backsliding | 回滚／回归缺陷／重新引入旧用法；分别指撤回已提交变更、功能退化和迁移过程中的旧用法复现。 |
| migration / deprecation / removal | 迁移／弃用／移除；保留渐进迁移、兼容过渡、最终删除的区别。 |
| flaky / brittle / nonflaky test | 不稳定测试／脆弱测试／不属于不稳定测试的测试；非不稳定不等于没有缺陷。 |
| transitive dependency / closure | 传递依赖／传递闭包；测试并集和逐分片复测交集分别保留。 |
| forwarding function / type alias | 转发函数／类型别名；用于新旧系统并存和非原子迁移。 |
| monorepo / repository / codebase | 单体代码仓库／代码仓库／代码库。 |
| code review / global approver | 代码审查／全局审批人；全局是权限范围，不是地理范围。 |
| mailing / submit | 邮件送审／提交；不混为推送或部署。 |
| unfunded mandate / organic migration | 只下达任务却不给相应资源的要求／自发迁移；保留集中承担成本及规模经济的论证。 |
| sublinear | 次线性；保留原文紧接的“大致相同人力时间”说明，不擅自将其改成严格常数复杂度定义。 |

工具及历史名称保留或据英文恢复：Google Template Library、TAP、Rosie、Kythe、ClangMR、JavacFlume、Refaster、perl、sed、google-java-format、clang-format、Tricorder、BigQuery、Operation RoseHub、Mad Gadget。`scoped_ptr`、`std::unique_ptr`、`NULL`、`nullptr`、OWNERS 和文件名保持原名，不替换为现代工具。
