## 复核命令

```bash
uv run --offline --locked --project tools --cache-dir .cache/uv python tools/chapter_pilot.py verify --chapter-only
uv run --offline --locked --project tools --cache-dir .cache/uv python -m unittest discover -s tools -p 'test_*.py' -v
git -c core.whitespace=-blank-at-eol diff --check
```

`chapter_pilot.py verify` 校验当前章节与逐行审定清单完全一致，再对照原基线验证保护内容及其他文件。
`report` 命令只重建本目录的对照和校验结果。`apply` 命令只接受原始章节或与当前清单完全一致的章节；
遇到其他改动会拒绝覆盖。
